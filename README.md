# Pathology Smart Gateway — Сайт-лендинг (`Ki-67` & `HER2`)

Официальный сайт-лендинг и интерактивная витрина проекта **Pathology Smart Gateway** — локального ИИ-шлюза цифровой патоморфологии рака молочной железы (автоматический подсчёт индекса пролиферации **Ki-67** и мембранного статуса **HER2** по полнослайдовым гистологическим изображениям WSI).

- **Основной рабочий продукт (MVP-стенд WSI):** [https://pathomorphology.streamlit.app](https://pathomorphology.streamlit.app)
- **Репозиторий лендинга:** [https://github.com/Vishovan/Pathomorfology_lending_page](https://github.com/Vishovan/Pathomorfology_lending_page)

---

## Ключевые возможности лендинга

1. **Плавные переходы между продуктами (`Ki-67` · `HER2` · `Панель Ki-67 + HER2`):**
   - Мгновенная смена визуального акцента, метрик, архитектуры ML-пайплайна, графиков финансовой модели и симулятора вьюера без перезагрузки страницы.
2. **Интерактивный симулятор `Pathology Smart Gateway`:**
   - Демонстрация детекции ядер (`StarDist2D` / `LSP-DETR`), оптической плотности `DAB` внутри ядра (`Ki-67`), замкнутости мембранного кольца `0 / 1+ / 2+ / 3+` по критериям `ASCO/CAP` (`HER2`), исключения лимфоцитов (`TILs`) и стромы из знаменателя, а также двойного расчёта **Hotspot (500 мкм)** и **Global**.
   - Клик по любому ядру на срезе переклассифицирует клетку и пересчитывает индекс в реальном времени.
3. **Калькулятор эффекта для заведующего ПАО / лаборатории:**
   - Расчёт экономии времени врачей-патоморфологов (протокол `IKWG` 8,5 мин → 2,0 мин с ИИ) и бюджета при тарифах `250 / 500 / 1 000 ₽` за стекло.
4. **Два режима просмотра (`Лендинг` и `Питч-дек 16:9`):**
   - Полноценный адаптивный скролл-лендинг и встроенный режим широкоэкранной презентации из 13 слайдов с управлением клавишами `←` / `→`.
5. **Прямой переход в рабочий стенд:**
   - Все ключевые CTA ведут на основной облачный стенд [https://pathomorphology.streamlit.app](https://pathomorphology.streamlit.app) с реальным серверным инференсом `StarDist2D (.h5)` и вьюером `OpenSeadragon`.

## Быстрый запуск локально

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Также поддерживаются URL-параметры для прямых ссылок на нужный продуктовый контур или режим презентации:
- `?product=ki67` — контур ИГХ Ki-67 (по умолчанию)
- `?product=her2` — контур ИГХ HER2 (0 / 1+ / 2+ / 3+)
- `?product=panel` — объединённая панель РМЖ (Ki-67 + HER2)
- `?view=deck` — запуск сразу в режиме презентации 16:9 (13 слайдов)
